# Вироблено в Україні

Статичний адаптивний сайт-каталог українських виробників, готовий до GitHub Pages.

## Як працює база

Під час першого відкриття дані один раз завантажуються з відкритої Google-таблиці та зберігаються у `localStorage`. Наступні відкриття використовують локальну копію без автоматичної синхронізації.

## Розробка

Сайт використовує Vercel Web Analytics для відстеження відвідувачів.

### Встановлення залежностей

```bash
npm install
```

### Збірка

Після внесення змін у `src/app.js`, виконайте:

```bash
npm run build
```

Це створить оптимізований bundle в `assets/app.js`.

## Публікація

1. Створіть репозиторій GitHub.
2. Завантажте всі файли з архіву в корінь.
3. Переконайтеся, що проект зібрано (`npm run build`).
4. Відкрийте **Settings → Pages**.
5. Оберіть **Deploy from a branch**.
6. Вкажіть `main` та `/ (root)`.
7. Натисніть **Save**.

Зібраний файл `assets/app.js` містить всі необхідні залежності, включаючи аналітику.
